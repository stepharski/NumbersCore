# Numbers Core



## Description

This Swift package provides the core logic for working with fun facts about numbers. It includes models, services, and storage utilities that interact with the Numbers API. This package is UI-independent and can be reused across apps or test targets


## Features

- Fetch number facts from the Numbers API
- Support for random facts, specific numbers, and date-based facts
- Core components separated from any UI layer
- Designed for testability and modularity
